# PRESCRIPT Prototype

「指令を受領する」形式の抽選Webアプリ試作品です。

## 起動方法

1. ZIPを展開します。
2. `index.html` をダブルクリックします。
3. Chrome / Edge などのブラウザで開きます。

インターネット接続は不要です。

## 現在できること

- 指令の追加
- 指令の削除
- ランダム抽選
- 簡易的な解析アニメーション
- 指令書表示
- 受領履歴の保存
- 遂行済みチェック
- ブラウザの localStorage にデータ保存

## 今回の追加
- 添付画像をイメージした白枠・黒背景・水色表示の受領端末
- 待機時は「****」が明滅
- 受領時にランダムな解析コードを高速表示
- PRESCRIPT → FOUND → READY の順に確定演出
- その後、従来どおり指令書を表示

## v6 変更点

## v11 AUDIO / REFINEMENT
- Web Audio APIで完全オリジナルの端末効果音を生成
- 解析開始: 低い機械起動音
